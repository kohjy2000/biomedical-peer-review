# Lenses

A lens is a short list of questions that a reviewer with a particular expertise asks routinely. Lenses make field intuition explicit so that a reviewer role in panel mode (see ../panel-review.md) applies it consistently.

Each lens entry has:

- **Question:** the generic question.
- **Trigger:** manuscript features that should prompt it.
- **Why it matters:** the inference that fails if the answer is unsatisfactory.
- **Literature support:** what to search for to answer it (for example, how comparable studies established the point, or the field definition of a term).
- **Example:** one generic, non-identifying example.

Load a lens during S2 only for the claims its triggers match. A lens prompts questions; it does not lower the evidence standard or replace claim-level appraisal.

Personal lenses derived from confidential review work should be kept outside this public repository (for example, in a local skills overlay) and loaded by path.
