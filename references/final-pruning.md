# Edit the complete review

The host applies this guide to the saved complete draft after the single scientific reassessment. Preserve the raw draft, save the checked detailed review as full-review.md, then produce the concise submission review. Save editing-notes.md describing consequential edits, source checks, compression and unresolved limitations. This is performed by the current assistant with its normal file/source tools, without a separate default model invocation. Use the accepted assessment, initial review, manuscript/figures and verified literature already supplied. This reference edits the author's required work and its presentation; it adds no separate appraisal stage or mandatory ledger.

## Resolve the requested actions

For every requested action, decide whether it is necessary for claim validity or a journal-appropriate contribution, optional strengthening, a defensible claim-calibration alternative, or unnecessary. Make the status consistent wherever the action appears. Present the minimum sufficient route, including multiple components when they are inseparable; state dependencies instead of making supporting measurements independent demands.

핵심 결론을 위해 해결해야 한다고 지적한 문제에는, 이를 해결할 수정 요구가 제시되어 있는지 확인한다. 특정 분석을 선택 사항으로 둔다면 기존 근거나 다른 수정으로 문제가 해결되는지 확인한다.

Keep alternatives only when they resolve the same inference. Additional presence, association or plausibility measurements cannot replace causal, functional, predictive or generalization evidence when that is the question. Claim narrowing is acceptable only when it resolves the issue and leaves a contribution appropriate for the journal.

## Preserve the checked detailed review

Check the draft's factual premises and requested actions against the supplied source, figures, assessment and literature. Correct errors and resolve required/optional inconsistencies before compression. Save this detailed version as full-review.md, separately from the untouched draft-review.md. It preserves useful reasoning and alternatives, not known errors. Record consequential judgment changes and source reasons in editing-notes.md.

## Compress in the selected template

Order comments by scientific consequence and prerequisite actions. Merge only when the underlying problem, consequence and remedy are the same. Consolidate repeated requests in one place. Label optional work within the selected template; use a separate Recommended section only if that template permits it.

Retain each consequential issue's manuscript-specific reason, interpretive consequence and sufficient remedy. Preserve useful discriminating comparisons and alternatives from the initial review unless the evidence justifies changing them. Remove repeated background and peripheral requests. For the default final report, aim for 600–1,000 words across Overall Assessment, Major Comments, Minor Comments and Recommendation. Respect a supplied user/journal format or length instead. Use focused connected paragraphs, normally one per major issue; do not expand each into labeled problem/reason/action/alternative fields. Keep only the source facts and literature rationale needed to support each judgment, with sufficient author actions and valid alternatives. Broader explanations remain in full-review.md or the dossier. Minor comments give the location and correction, normally in one sentence.

The range is not a hard cap and there is no fixed number of comments. If independent consequential issues need more space, exceed the target and explain why in editing-notes.md. Do not weaken a required action, omit its reason, or remove a valid alternative merely to save words.

## Check the actual final text

Compare the concise final text with full-review.md, the accepted assessment and useful initial-review reasons/actions. Record the draft/full/final word counts and where consequential issues were retained, merged, corrected or removed; reasons for substantive removal belong in editing-notes.md. Check that the study's contribution, central uncertainty and highest-value author actions remain explicit; each major comment explains its scientific consequence and remedy; no action is both required and optional; alternatives answer the same question; and the recommendation follows from the surviving issues and feasible remedies.

Recheck shortened factual statements, claim verbs, counts, quotations and absence assertions against the supplied source, including figures when relevant. If editing reveals an invalid alternative or would change a scientific judgment, resolve it against that evidence. Preserve the raw material_changes field and record any subsequent consequential judgment changes with source reasons in editing-notes.md; do not turn internal process records into the author-facing review.
