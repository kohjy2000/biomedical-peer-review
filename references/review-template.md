# Author-facing review template

Use the user or journal's supplied template when present. This default preserves the user-provided Overall Assessment / Major / Minor structure and explicit Problem → Why it matters → Action format. Keep claim maps, literature logs and process records in the working dossier. Replace the bracketed prompts with manuscript-specific content; omit empty optional sections. There is no default word or comment count.

## Overall Assessment

[What the evidence actually establishes; why that contribution matters in light of prior work; the central remaining uncertainty; what the authors should resolve first. Calibrate the assessment to the manuscript type and journal. A well-supported conclusion need not generate a criticism.]

## Major Comments

### 1. [Short title identifying the scientific issue]

**Problem.** [The specific observation, comparison, measurement, analysis or claim at issue, with its manuscript location.]

**Why it matters.** [How this changes the interpretation, contribution, claim validity or journal-level adequacy. Include the relevant literature reasoning only when needed.]

**Action.** [The minimum required correction or evidence and what it must establish. State necessary dependencies. For experimental requests, distinguish routes using the labels below when an acceptable alternative exists.]

- **Plan A:** [A feasible direct route resolving the stated inference.]
- **Plan B:** [An equivalent evidentiary route, or a specific narrower claim with limitations, only if it resolves the problem and leaves a journal-appropriate contribution. If there is no defensible alternative, explain the necessary requirement without inventing Plan B.]
- **Optional strengthening:** [Include only material additional value beyond the minimum; clearly non-required.]

[Repeat for independent consequential issues, ordered by scientific consequence and what must be resolved first. For a simple correction, write the Action directly without artificial Plan A/B alternatives.]

## Minor Comments

- **Line / Figure / Table / Methods location:** [Specific problem and correction.]

## Literature Notes (optional)

[Include only useful literature context not already needed within a comment. Distinguish essential positioning corrections from suggested reading; avoid repeated background.]

## Recommendation (when requested)

[Use the journal's options; base the decision on the remaining issues, feasible remedies, and the contribution after adequate revision.]

## Comment to Editor (confidential, when needed)

[Scientific value, central publication barrier, whether adequate revision is feasible and would meet the journal's bar. Keep author-actionable criticisms in the author-facing review.]
